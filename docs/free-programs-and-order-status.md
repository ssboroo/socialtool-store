# Үнэгүй программ ба захиалгын төлөв

## Админ

Бүтээгдэхүүн → Шинэ бүтээгдэхүүн (эсвэл дэлгэрэнгүй засвар) → **Үнэгүй программ** сонгоод нэр, ангилал, HTTPS **Татах URL** оруулж хадгална. Үнэ 0₮ болно; хуучин үнэ болон лицензийн хугацааны төлбөртэй сонголтууд хадгалагдахгүй. Холбоос нь албан ёсны файл эсвэл татах хуудас байж болно. Файл сайт дээр байршуулах шаардлагагүй.

Үнэгүй программын хурдан засварт үнэ өөрчлөхгүй; “Татах URL засах” товчоор дэлгэрэнгүй засварт шилжинэ. Үнэ бөөнөөр өөрчлөх, нийлүүлэгчийн автомат шинэчлэлт, CSV импорт нь үнэгүй программыг төлбөртэй болгож дарж бичихгүй. Төлбөртэй болгох шаардлагатай бол дэлгэрэнгүй засварт үнэгүй сонголтыг унтрааж эерэг үнэ оруулна.

## Хэрэглэгч

**Үнэгүй программууд** ангиллаас программ сонгоно. Карт болон дэлгэрэнгүйд **Үнэгүй татах** холбоос шинэ цонхонд нээгдэнэ. Сагс, төлбөрийн захиалга үүсэхгүй. Түр идэвхгүй программын татах товч ажиллахгүй.

Нэвтэрсэн хэрэглэгчийн **Миний захиалга** хэсэгт “Захиалга үүссэн → Төлбөр баталгаажсан → Хүргэгдсэн” явц, төлбөр баталгаажсан огноо, одоо байгаа хүргэлтийн мэдээлэл харагдана. Цуцлагдсан захиалгыг тусад нь тэмдэглэнэ. Нээлттэй үед 30 секунд тутам, цонхонд буцаж ирэхэд эсвэл “Төлөв шинэчлэх” дарахад серверээс төлөв авна. Төлбөр амжилттай болсон цонхноос захиалгын төлөв рүү шууд орж болно.

Бүртгэлтэй захиалгын түүх зөвхөн тухайн хэрэглэгчид харагдана. Зочноор хийсэн өмнөх захиалгуудыг данс руу и-мэйлээр автоматаар холбохгүй; зочны одоо байгаа төлбөрийн баталгаажуулалт, захиалгын чат хэвээр.

## Нэвтрүүлэх

`Product.downloadUrl` nullable String багана нэмэгдсэн. Одоогийн бүтээгдэхүүнүүдийн утга null хэвээр байна. Өгөгдлийн сангаа нөөцөлж, зөв persistent SQLite `DATABASE_URL` тохирсон сервер дээр шинэ кодыг ажиллуулахаас өмнө:

```sh
npx prisma db push
npx prisma generate
npm run build
```

Reset, seed болон `--accept-data-loss` хэрэглэхгүй. Өгөгдөл устгах анхааруулга гарвал зогсоож шалгана. GitHub руу код оруулсан нь live серверийн schema/deploy хийгдсэнийг батлахгүй.

## Шалгалт

- `npm run build`: production build ба TypeScript.
- `npm run lint` / `node node_modules/eslint/bin/eslint.js src tests scripts`.
- `TEST_DATABASE_URL` нь OS temporary хавтас дахь тусгаарласан SQLite санг заасан үед `node --test tests/*.test.mjs`: HTTPS URL, free/paid invariant, API CRUD, төлбөрт оруулахгүй хамгаалалт, захиалгын төлөв ба хэрэглэгчийн тусгаарлалт.
- `tests/free-orders.browser.mjs`: локал админаас үнэгүй программ нэмэх, карт/дэлгэрэнгүй татах холбоос, mobile захиалгын төлөв ба шинэчлэлт. `TEST_ADMIN_USERNAME`, `TEST_ADMIN_PASSWORD`, шаардлагатай бол `PLAYWRIGHT_MODULE`, `CHROME_EXECUTABLE` тохируулна. Бодит төлбөр эсвэл production сан ашиглахгүй.
- `tests/storefront-design.browser.mjs`, `tests/customer-account.browser.mjs`: зургаан дэлгэцийн өргөн, хуудаслалт, account error/retry/logout regression.
