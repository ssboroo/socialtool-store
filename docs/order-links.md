# Захиалгын холбоос (Socialtool.store)

## Хэрэглэгчид
Төлбөр төлөх цонхонд бараа тус бүрийн доор **Захиалгын линк** талбар байна.
- Линк шаарддаг бараанд од (`*`) харагдаж, хоосон байвал захиалга үүсэхгүй.
- Бусад бараанд талбар харагдана, хоосон үлдээж болно.
- Зөвхөн `https://` холбоос (2,048 тэмдэгтээс ихгүй) зөвшөөрнө.
- Олон бараатай сагсанд тус бүрийн холбоосыг тусдаа хадгална.

## Админд
**Админ → Бүтээгдэхүүн → Засах** (эсвэл хурдан засвар) дотор
`Захиалгын линк шаардах` сонголтыг идэвхжүүлнэ. Үнэ төлбөргүй
татах програмд энэ тохиргоо хамаарахгүй.

Захиалга ирсний дараа **Админ → Захиалгууд → Дэлгэрэнгүй**
дотор оруулсан холбоос харагдаж, нээх болон хуулах товчтой байна.
Захиалгын Telegram мэдэгдэлд холбоос орно.

## Production database migration
Энэ өөрчлөлт `Product.requiresOrderLink` болон `OrderItem.orderLink`
гэсэн хоёр багана нэмнэ. Өмнөх өгөгдлийг устгах шаардлагагүй.

**Шинэ кодыг байрлуулахаас өмнө**, production SQLite өгөгдлийн сангаа
нөөцлөөд зөв `DATABASE_URL`-тай орчинд:

```bash
bunx prisma db push
```

`--accept-data-loss` бүү ашигла. Migration амжилттай болсны дараа
шинэ кодоо deploy хийнэ.

Дараахыг шалга: энгийн бараа холбоосгүй захиалагдана; холбоос шаардсан
бараанд холбоосгүй захиалга серверээр хориглогдоно; HTTPS холбоостой
захиалга админд зөв харагдана; QPay төлбөр хуучнаараа ажиллана.
